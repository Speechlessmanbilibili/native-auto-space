# 中西文自动间距 · 案头工作台前端

设计与实现日期：2026-10-17。

## 视觉语言

- 三款扩展共用“案头”设计系统：暖纸底色、墨色正文、细线与衬线标题。本扩展主色为松绿 `#3c6650`，深色模式使用 `#9cc7ac`。
- 界面字体通过 `@font-face` 与 `unicode-range` 拆成中西文两组本机别名。中文引号、破折号、省略号、间隔号与全角标点由中文字体排，西文、数字与代码符号由西文字体排；标题使用衬线别名。
- 颜色令牌集中在 `kit/kit.css`：纸 `#f4f0e7`、纸面 `#fffcf5`、墨 `#211f1b`、次级文字 `#4f4a43`；暗色使用暖黑纸面与米色文字。
- 页面标识、工具栏与扩展管理页沿用同一书籍印记；PNG 提供 16、32、48、128 像素。

## 交互与适配

- 顶部应用栏固定：保存状态与保存设置始终可达。
- 设置页为单列工作台：全局默认、排版对照、网站规则与说明依次排列；窄屏把并排试样改为上下对照。
- 开关、分段三态、站点规则与折叠说明由 `kit/` 统一提供，保留原生表单语义、焦点环与键盘操作。
- 支持明暗主题、强制颜色、减少动效、窄屏与 200% 缩放；保存成功、失败与未保存状态分别显示。

## 页面结构

1. 全局默认：总开关与当前状态。
2. 排版对照：左侧原样，右侧按当前草稿应用 `text-autospace`，两侧原文字完全相同；关闭全局后右侧恢复原样。
3. 网站规则：域名、规则数量、三态选择与删除；更具体的域名优先，填写端口时只匹配该端口。
4. 说明：浏览器版本要求、受保护页面限制与关闭后的行为。

工具栏弹窗依次显示当前域名、本站三态、生效结果、全局默认与设置入口。样张原文为 `中文与English、数字2026自然衔接。`，间距由浏览器排版完成，不插入空格。
